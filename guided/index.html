guided checks

Questions a tool cannot answer, each with the fixture to ask it against and a slot for the evidence.

Every one of these has an expected automated outcome of cannot-tell. That is the correct result, not a hedge: a tool returning pass here is overclaiming, and one returning fail is guessing.

  • Do instructions rely on shape, size, position, sound or colour alone? — guided-manual, 1.3.3

  • Do the pauses allow every important visual detail to be described? — guided-manual, 1.2.7
  • Is there a live equivalent for the live audio-only content? — guided-manual, 1.2.9
  • Is the background at least 20 dB below the foreground narration? — guided-manual, 1.4.7
