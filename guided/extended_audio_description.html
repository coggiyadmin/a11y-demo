Do the pauses allow every important visual detail to be described?

Method: guided-manual · Criteria: 1.2.7 · Automated outcome: cannot-tell

Why automation cannot decide this

Standard audio description fits into existing gaps in the dialogue. Deciding that those gaps are too short, and that the video must be paused to say more, requires knowing what the picture carries that the soundtrack does not.

When this does not apply

This criterion is inapplicable inapplicable when foreground audio pauses already allow full description. Recording inapplicable is a correct result here, not a gap.

How to check it

  1. Watch with the picture hidden and list what becomes unclear.
  2. Compare that list with what the description actually says.
  3. Check whether the existing pauses could carry the missing detail without extending them.
  4. Only then decide whether extended description is required.

Evidence to capture

The description script, the media, and the list of details lost without the picture.
