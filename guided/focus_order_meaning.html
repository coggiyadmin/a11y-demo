Does the focus order preserve meaning and operability?

Method: guided-manual · Criteria: 2.4.3 · Automated outcome: cannot-tell

Why automation cannot decide this

A tool can record the tab sequence. Whether that sequence makes SENSE for the task is a judgement about the task, not the DOM.

How to check it

  1. Tab through the page from the top without using a mouse.
  2. Check the order matches how the task is meant to proceed.
  3. Check nothing receives focus that should not, and nothing is skipped.

Evidence to capture

Numbered screenshots of each focus stop.
