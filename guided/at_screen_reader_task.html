Can a screen-reader user complete the task from start to finish?

Method: at-testing · Criteria: 2.1.1, 4.1.2 · Automated outcome: cannot-tell

Why automation cannot decide this

This is the only check that answers the question the others approximate. It needs a real screen reader and a person who uses one; results do not transfer between pairings, so a pass with one is not a pass with another.

How to check it

  1. Pick a pairing — NVDA+Firefox, JAWS+Chrome, VoiceOver+Safari, TalkBack+Chrome.
  2. Complete the whole task using only the screen reader.
  3. Record where progress stalls, not only where a rule is broken.
  4. Repeat on a second pairing before concluding anything.

Evidence to capture

Screen and audio recording, naming AT and browser versions.
