Does the DOM order match the meaningful reading order?

Method: guided-manual · Criteria: 1.3.2 · Automated outcome: cannot-tell

Why automation cannot decide this

CSS can reorder content visually while the DOM stays unchanged. A tool sees a valid DOM and a valid layout; only a person can say the two tell different stories.

How to check it

  1. Disable CSS and read the page top to bottom.
  2. Compare that order with the visual order.
  3. Check any difference does not change meaning.

Evidence to capture

Screenshot with CSS on and the unstyled DOM order side by side.
